### Step 3：实现不可变快照

`StrategyStatusSnapshot` 只允许持有一份不可变 `List<String>`：

```java
public final class StrategyStatusSnapshot {
    private final List<String> lines;

    private StrategyStatusSnapshot(List<String> lines) {
        this.lines = Collections.unmodifiableList(new ArrayList<String>(lines));
    }

    public static StrategyStatusSnapshot from(SimState state) { /* 按下述规则实现 */ }
    public List<String> lines() { return lines; }
}
```

`from` 的精确规则：

1. 按槽位下标遍历 `state.potions`；空格累计后只加一行 `药空槽 ×N`。
2. 主动药：基础格式 `药[slot] id · 主动[/{目标|选牌}] · 门槛 N HP`；`needsTarget` 优先于 `needsChoice`。
3. 被动药：`药[slot] id · 被动 · 无主动使用门槛`，不得调用后展示默认 9 HP。
4. 遗物行拼接所有 `state.relics`，保持 `TreeMap` 顺序，格式 `遗物 id=counter · ...`。
5. `Coverage.unmirroredRelics(state)` 非空时另加 `未镜像遗物 N: id, id`。
6. 成长行以 `成长 hp/max {hp}/{maxHp}` 开头；只按固定顺序追加 `Strength`、`Dexterity`、`Demon Form` 且 `amount > 0` 的项；三项都没有则追加 `· 无关键成长层数`。
7. 不调用 `PowerValuation.persistentBuffValue`，不读 `BeamSolver` 私有遥测，不创建任何设置项。

### Step 3：实现最小纯数据目标类

`BoundedAutoTarget` 为 package-private，字段只有 `int targetTurn = -1`：

- `request(target, current)`：两者均 ≥1 且 target ≥ current 时保存并返回 true；否则不改旧值并返回 false。
- `shouldStop(current)`：仅 `isActive() && current > targetTurn`。
- `clear()`：恢复 -1。
- `isActive()` / `targetTurn()`：只读。

不要在单元测试中实例化 `AutoPilot` 或 STS1 游戏对象。

### Step 4：接入 AutoPilot 生命周期

1. 增加静态 `BoundedAutoTarget` 和：

```java
public static boolean runUntil(int targetTurn);
public static int stopAfterTurn(); // 无目标返回 -1
public static int currentTurn();   // 主线程读取真实绝对回合，供 UI 拒绝过期行
```

2. `runUntil` 只能在主线程执行入口调用：通过 `currentTurn()` 读取真实回合，校验 `BoundedAutoTarget.request`；失败记录 warn 并返回 false，不改变 AUTO。
3. AUTO 已开时只替换目标；AUTO 未开时按 `toggle()` 开启分支的同样清理开启，但**不得调用 toggle 造成反向翻转**。
4. 成功设置目标、替换目标、清目标都递增 panelRevision；记录 `AUTO bounded start target=Tn current=Tm`。
5. 普通手动 `toggle()` 开启的是无界 AUTO，先清目标；关闭时也必须清目标。
6. 新建统一 `stopAuto(String reason)`：所有现有 `enabled = false` 路径（disable、toggle-off、异常、连续卡死、复现失败等）都经它清目标。`reset()` 同样清目标。
7. `clearPlan()`、指纹失配、ShadowTracker 失配、药水后重算、搜索等待都**不得**清目标。
8. 不新增 `AsyncSearch.reset()` 调用；点击路线不等于取消后台搜索。

### Step 5：在准确边界停止

`tick()` 顺序固定为：

1. settled 快照泵（只展示，不执行）；
2. enabled 早退；
3. 更新 `turnNow` 与既有回合变化清理；
4. `waitingForNextTurn()` 若仍等待则返回；
5. **在任何搜索、出牌、喝药或 END_TURN 前**检查 `boundedTarget.shouldStop(turnNow)`；
6. 到期时先保存目标用于日志，再 `stopAuto("bounded complete")`，打印 `AUTO bounded stop after Tn; control returned at T(n+1)`，立即 return；
7. 其余现有逻辑不变。

不得在 `requestEndTurn()` 立即停；Tn 的敌方阶段必须完整结束。战斗结束仍由 `CombatCapture` / `reset()` 优先清理。

### Step 6：接路线点击与目标视觉

`SolverPanel.update()`：
