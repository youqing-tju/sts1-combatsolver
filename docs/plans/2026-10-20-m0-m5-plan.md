## M1 · 影子状态 + 镜像骨架 + 差分台架

**目标**：影子引擎能复现「初始牌组 vs 大颚虫」这一场战斗，且与真机逐字段一致。

| # | 任务 | 验收 |
|---|---|---|
| M1-1 | `capture/RootSnapshot`：主线程抓取完整根状态（含随机数种子+计数器、有序牌堆） | 单帧抓取成功，字段无遗漏 |
| M1-2 | `sim/` 影子数据结构：玩家/怪物/三个牌堆/能量/能力/遗物计数 | 可从快照重建，A1 diff = 0 |
| M1-3 | 随机数复刻：复用游戏的 `Random`（纯计算，线程安全）+ `copy()` | 连续 1000 次抽数与真机逐一致 |
| M1-4 | `mirror/` 注册表：卡牌/能力/遗物 条目 + 支持状态 + **显式拒绝** | 未登记条目一律拒绝，有日志 |
| M1-5 | 伤害管线：力量/虚弱/易伤/格挡/荆棘等修正 | 单测覆盖每种修正 |
| M1-6 | 初始牌组 5 张 + `Bash` 的镜像 | 与真机同动作结果一致 |
| M1-7 | `verify/` 差分台架：真机动作序列 → 影子重放 → 逐字段比对 | **A2 一致率 100%（初始牌组范围内）** |
| M1-8 | 单节点耗时基准 | 记录基线（目标 ≤ 1 ms） |

**风险点**：M1-6 之前不要写搜索——先证明「影子是对的」。
